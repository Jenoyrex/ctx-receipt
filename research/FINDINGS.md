# Findings: what popular repositories pre-load into AI coding agents

Generated by `research/summarize.mjs` from `research/scan-2026-11-14.json`. Every number
below is computed from that file; `test/research.test.ts` fails if this page and the data
disagree. All token counts are **estimates** (o200k_base via gpt-tokenizer, ctx-receipt
0.1.2); Claude's own tokenizer counted about 1.6 times as many on the same
text in our comparison with Claude Code's `/context`.

## Method

- **Pool:** GitHub search "stars:>1000 archived:false pushed:>=2026-09-15", sorted by stars, first 1,000 results (1,000 repositories).
- **Filter:** default branch has at least one of: AGENTS.md, CLAUDE.md, .claude/CLAUDE.md, CLAUDE.local.md, GEMINI.md, .cursorrules, .cursor/rules, .claude/rules, .claude/skills, .claude/agents, .agents/skills, .gemini/skills; forks excluded. 487 of the 1,000
  (49%) passed.
- **Sample:** the 50 most-starred repositories that pass the filter, on 2026-11-14.
- **Measurement:** `ctx-receipt <repo> --no-user --home <empty dir> --json` on a shallow, sparse clone of each default branch (top-level
  files, the agent folders, and files named by `@` imports). Project files only: no home-folder
  configuration, no MCP servers started.
- **Measured:** 50 of 50 repositories. Not measured:

- none

## Headline

For each repository we take the agent that pre-loads the most, since that is what one session
pays before the first prompt.

| n | min | 25th percentile | median | 75th percentile | max |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 50 | 78 | 755 | 1,838 | 4,001 | 12,446 |

The median repository asks its heaviest agent to pre-load **1,838 tokens**; half of
the repositories fall between 755 and 4,001.

Grades (ctx-receipt's own cut-offs, A under 5k): A: 42, B: 8, C: 0, D: 0, F: 0.

## Where the tokens come from

- **Rules files and skills.** Of the always-loaded tokens of each repository's heaviest agent,
  84% come from rules files (AGENTS.md, CLAUDE.md, and their imports) and
  16% from skill listings.
- **The largest single file.** The largest always-loaded file per repository has a median of
  1,651 tokens and a maximum of 12,446.
- **Skills.** 16 of 50 repositories ship skills; in 2 of them the skill
  listing reaches an agent's listing cap at the default 200k window, so the agent trims
  descriptions.
- **Formats.** 45 of 50 have `AGENTS.md` at the root; 23 have
  `CLAUDE.md`.
- **On demand.** Content that loads only when used (skill bodies, path-scoped rules), for each
  repository's largest agent: median 0, 75th percentile
  4,162, max 119,261 tokens.

## Limits

- Estimates, not each agent's own count. Claude's tokenizer gave about 1.6 times our number on
  the same text.
- Project files only. Each developer's own home configuration, plugins, and MCP servers add to
  these numbers and are not included.
- Agents' own system prompts and built-in tools are not included.
- A shallow, sparse clone of the default branch at one moment; files in subfolders that load on
  demand are not counted.
- Symlinks are checked out as plain files for safety. 11 symlinked files in
  8 repositories point inside their repository and were replaced by their
  target's content, as an agent would read them; 44 point outside and were left
  as they are.
- The sample is popular repositories, not a random sample of all projects.

## Reproduce

```bash
npm install && npm run build
node research/select.mjs                      # needs the GitHub CLI; picks the sample
node research/scan.mjs research/selection-2026-11-14.json
node research/summarize.mjs research/scan-2026-11-14.json
```

Selection and scan results change as repositories change; the committed files record this run.
